# 配置面变更审计（`sys_change_audit`）设计

> 状态：`IMPLEMENTED`（2026-11-13）
> 关联：`CR-20261114-042`、断言 #109
> 一句话：回答"某个配置是谁在什么时候从什么值改成了什么值"。

## 1. 为什么需要

操作日志（`sys_oper_log`）记的是**请求**：谁、什么接口、参数、耗时、结果。它**只有新值、没有旧值**——所以"参数被改成 1 秒超时"这类事故只能查到"某人点了保存"。

配置面又是最需要旧值的地方：它们不改数据，改**系统行为**。

| 配置面 | 改错的症状 |
|---|---|
| 登录失败阈值 / 锁定时间 | 全员被锁，或爆破防护失效 |
| Token 有效期 | 频繁掉线，或过期形同虚设 |
| 导出上限 / 上传大小 | 大批量操作突然 400 |
| 字典项 | 历史数据渲染成空白（值还在，含义变了） |
| 菜单 / 角色授权 | 整块功能消失或越权可见 |

没有 diff，这些问题只能靠猜。

## 2. 与操作日志的分工

| | 操作日志 `sys_oper_log` | 变更审计 `sys_change_audit` |
|---|---|---|
| 粒度 | 请求 | 对象 |
| 记录 | 接口、参数（JSON 快照）、耗时、结果码 | 对象键、**before/after**、操作人、IP、traceId |
| 覆盖 | 所有被 `@OperLogRecord` 标注的写接口 | 只覆盖配置面四类：参数 / 字典 / 菜单 / 角色授权 |
| 用途 | 排障、追责、性能 | "这个键的历史轨迹" |

两者互补，不互相替代。

## 3. 数据模型

一张泛化表，不为每类配置建一张：

| 列 | 说明 |
|---|---|
| `target_type` | `CONFIG` / `DICT_TYPE` / `DICT_ITEM` / `MENU` / `ROLE_GRANT` |
| `target_key` | 业务键：参数键 / `字典编码:值` / 菜单 path 或权限码 / 角色 code |
| `target_name` | 可读名（列表展示） |
| `action` | `CREATE` / `UPDATE` / `DELETE` / `GRANT` |
| `before_value` / `after_value` | JSON 快照（UPDATE 只放变化字段） |
| `is_sensitive` | 敏感对象标记（快照整体打码） |
| `operator_id` / `operator_name` / `ip` / `trace_id` / `created_at` | 追责与关联 |

索引：`(target_type, target_key, created_at)`（按对象看轨迹）+ `(created_at)`（按时间巡检）。

## 4. 三条写入口径（断言 #109）

1. **只记"变了什么"**：UPDATE 只保留值发生变化的字段；无变化**不写**（否则"点一下保存"就污染轨迹）。
2. **敏感对象两侧都打码**：`sys_config.is_sensitive=1` 的 before/after 一律 `******`。只掩新值等于把明文搬到旧值列里存一遍。
3. **留痕失败不阻断业务**：仓储异常吞掉并 warn；但留痕与业务**同一事务**——业务回滚则留痕一并回滚，保证"没改成就不留痕"。

## 5. 只读约束

- 没有写入口：`ChangeAuditController` 只有 `GET`；写入只能由业务事务内的 `ChangeAuditRecorder` 产生。
- 所以任何外部调用都**造不出**审计记录（集成测试有专门断言）。
- 页面同样只读：没有新增/编辑/删除按钮。

## 6. 覆盖点

| 服务 | 落点 |
|---|---|
| `ConfigAppService` | create / update / delete |
| `DictAppService` | 字典类型与字典项的 create / update / delete |
| `MenuAppService` | create / update / delete |
| `RoleAppService` | `assignMenus`（角色↔菜单授权） |

## 7. 明确不做

- **不做全量数据表的行级审计**：给每张业务表加影子表/触发器，成本爆炸，等保不要求。
- **不做留存归档**：等保要求的"留存 ≥6 个月"是另一项（定时归档 + 冷表），用户此前已明确搁置。
- **不做防篡改**（哈希链）：同上，属等保 P0 剩余项。
- 不记"谁看了什么"（读审计），只记写。
