## 1. 背景

`ExcelExportWriter`（导出写表器）与 `ExcelTemplateWriter`（模板生成器）是两个"用户唯一能看到/能填写"的产物：

- 导出文件是**数据外流的最大出口**——掩码字段的列是否输出、导出的是显示值还是原始 ID，都在这里决定；
- 模板是用户填写的唯一依据——必填标记漏一个用户就不知道要填，数据页名与导入期望不一致会让整份文件被判"缺少数据页"。

两者此前只有间接覆盖（`ExcelExportPlannerTest` 用 mock 掉了写表器）。

## 2. 范围（+11 用例）

### `ExcelExportWriterTest`（8）

| 用例 | 锁定 |
|---|---|
| 表头 | 与 schema 的导出表头完全一致（不多不少、顺序一致） |
| 枚举 | 导出中文含义；未知存储值**原样输出不丢数据** |
| 引用字段 | 部门导出完整路径、负责人导出「姓名（部门）」，不是原始 ID |
| 掩码 · view | 有 `view` 权限 → 明文 |
| 掩码 · mask | 只有 `mask` 权限 → 掩码值 |
| **掩码 · 无权限** | **该列整列不输出**（不是输出空串） |
| 空值 | 写空串而不是字面 `null`（否则再导入会报格式错） |
| 流式导出 | 分页取数直到 `null`（空页不算结束）、返回总行数、进度回调 |

### `ExcelTemplateWriterTest`（3）

| 用例 | 锁定 |
|---|---|
| 数据页表头 | 必填列带 `*`；只包含参与导入的字段（只导出不导入的字段不出现） |
| 下拉引用页 | 枚举列有隐藏的「引用数据」页且下拉源含全部可选值（内联下拉受 255 字符限制） |
| 填写须知页 | 说明「整批校验通过才写入、任一行有错整批不落库」；逐列写必填/选填与字数上限 |

## 8. 自我纠正（都发生在测试代码里，非产品缺陷）

1. `ExcelTemplateWriter` 不是无参构造（依赖 `ReferenceDirectoryService`），我按无参写了第一版 → 改为传入空实现；
2. 流式导出的"取页次数"我算了两次都错：`cursor++` 只在返回数据页的分支执行，空页算一次、`null` 不算 → 最终断言 `pages.size()`，并把语义写进注释（空页不能当结束条件）。
