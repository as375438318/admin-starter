## 1. 背景

分片合并是"最后一道闸"：分片可以一个个传上来，只有这里会确认**拼起来的东西就是用户声明的那个文件**。少一道校验用户拿到的就是损坏文件；忘了清理分片目录，磁盘会被临时片慢慢吃满。

## 2. 范围（+10 用例，`FileChunkCompleteTest`，真实 `LocalFileStorage` + `@TempDir`）

| 用例 | 锁定 |
|---|---|
| 会话状态非 `UPLOADING` | 拒绝（冲突），不重复合并 |
| 分片不完整 | 报「缺少第 N 片」（用户知道该重传哪片） |
| 合并后大小不符 | 拒绝，不建记录 |
| **合并后整体 sha256 不符** | 拒绝并提示重新上传，不建记录、不改会话状态 |
| 合并成功 | 字节落盘、建记录（原名/大小/sha/上传人）、**清理分片目录**、会话置 `MERGED` |
| 合并成功且已有相同内容 | 复用存储路径 + 标记秒传，仍建新记录 |
| 放弃会话 | 清分片 + `UPLOADING` → `ABORTED` |
| 放弃已完成会话 | 只清分片，**不覆盖 `MERGED`**（避免把成功记录标成放弃） |
| `MERGED` 后再传分片 | 状态冲突（状态机不允许回退） |
| 匿名合并 | 被拒（合并要建记录，必须有人可归属） |
