# 登录与自测说明

> 版本：v1.0（2026-11-08）
> 适用：本机已按 `pnpm workspace` 多端结构迁移后的可运行脚手架（`apps/pc` + `server`）。
> 说明：服务是本机**手动启动**的，机器重启或终端会话结束后需要按第 6 节命令重新启动。

## 1. 访问地址

| 项 | 地址 |
|---|---|
| 前端（PC 端） | `http://127.0.0.1:5173`（`http://localhost:5173` 也可） |
| 后端接口基址 | `http://127.0.0.1:8082/api/v1` |
| 后端健康检查 | `GET http://127.0.0.1:8082/api/v1/auth/me`，未登录返回 **401** 信封即表示服务已就绪 |
| 前端代理 | 前端把 `/api` 代理到 `http://127.0.0.1:8082`，浏览器只需访问 5173 |

## 2. 管理员账号

| 用户名 | 口令 | 部门 | 角色 | 数据范围 | 归属过滤 |
|---|---|---|---|---|---|
| `admin` | `admin123` | 总部 | 超级管理员 | `ALL` 全部 | `NONE` 不过滤 |

`admin` 具备全部功能权限，用它做功能走查；切换账号做数据权限验证。生产环境必须改口令。

## 3. 测试账号清单（口令统一为 `admin123`）

| 用户名 | 口令 | 所属部门 | 角色 | 数据范围（6 档） | 归属过滤（3 档） | 适合验证 |
|---|---|---|---|---|---|---|
| `admin` | `admin123` | 总部 | 超级管理员 | `ALL` 全部 | `NONE` 不过滤 | 功能权限全量、数据权限对照组（不看被过滤） |
| `demo_dept` | `admin123` | 研发部 | 部门范围示例 | `DEPT` 仅本部门 | `NONE` 不过滤 | **本部门隔离**（看不到下级与跨部门） |
| `deptmgr` | `admin123` | 研发部 | 部门管理员 | `DEPT_AND_CHILD` 本部门及下级 | `NONE` 不过滤 | **下级可见**（本部门 + 研发一组） |
| `auditor` | `admin123` | 财务部 | 跨部门审计 | `CUSTOM_DEPT` 指定部门（研发部、市场部） | `NONE` 不过滤 | **跨部门指定范围** |
| `viewer` | `admin123` | 财务部 | 指定人员观察者 | `CUSTOM_USER` 指定人员（`dev2`） | `NONE` 不过滤 | **指定人员**（只看 `dev2` 创建的数据） |
| `dev1` | `admin123` | 研发一组 | 普通员工 | `SELF` 仅本人 | `CREATOR` 仅本人创建 | **多角色并集 / 缓存失效**（给 `dev1` 加 `ALL` 角色后再移除） |
| `dev2` | `admin123` | 研发一组 | 普通员工 | `SELF` 仅本人 | `CREATOR` 仅本人创建 | 指定人员场景的**被观察对象**（`viewer` 的目标用户） |
| `market1` | `admin123` | 市场部 | 普通员工 | `SELF` 仅本人 | `CREATOR` 仅本人创建 | 普通员工基线（只看自己创建的） |
| `demo_owner` | `admin123` | 市场部 | 负责人过滤示例 | `ALL` 全部 | `OWNER` 仅本人负责 | **`OWNER` 归属过滤**（演示业务表 `owner_id` 显式标注） |

> 6 档数据范围取值：`ALL`／`DEPT`／`DEPT_AND_CHILD`／`SELF`／`CUSTOM_DEPT`／`CUSTOM_USER`。
> 3 档归属过滤取值：`NONE`／`CREATOR`／`OWNER`。页面上显示中文标签，提交值为上述英文枚举。

## 4. 示例业务表入口

- 路径：`http://127.0.0.1:5173/demo/tasks`
- 菜单位置：登录后左侧菜单**顶级项「示例业务」**（不在“系统管理”下），图标与其它一级菜单同列。
- 页面能力：列表（sticky 表头 / 分页 / 骨架屏）、新增、编辑、删除，按钮按权限码 `demo:task:create` / `demo:task:update` / `demo:task:delete` 控制；筛选含关键词、归属部门、状态。
- 该页面就是数据权限的参考实现：所有列表查询都走 SQL 层行过滤，越权详情返回 404。

## 6. 服务启动命令（重启后照此执行）

```powershell
# 1) 后端（根目录执行；Maven 默认可能是 JDK 8，需先指向 JDK 17）
$env:JAVA_HOME = "<你的 JDK 17 安装目录>"
cd server
mvn -B -DskipTests spring-boot:run

# 2) 前端（另开一个终端，在仓库根目录执行）
pnpm install   # 首次或依赖变更后执行
pnpm dev       # 启动 5173 dev server
```

后端依赖本机 MySQL 8（`127.0.0.1:3307`，库 `admin_starter`）与 Redis（`127.0.0.1:6379`）；首次启动需准备 `server/web/src/main/resources/application-local.yml`（见 `README.md`）。
