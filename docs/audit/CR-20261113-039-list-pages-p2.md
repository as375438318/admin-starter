| 列表 | 处理 | 理由 |
|---|---|---|
| 文件列表 `/files` | **新增** `SORTS`（createdAt / originalName / size / id），`page(keyword,page,pageSize,sort,order)` | 原来写死 `created_at desc` |

## 5. 复核时确认的 4 处判断（都认可并保留）

1. **`message` 的「标题」设为常显**：它不是固定列也不是操作列，但它是收件箱**唯一的详情入口**，隐藏后整行不可点 —— 可用性优先于"只让固定列常显"的形式约定。
2. **`job`「任务名称」/ `notice`「标题」常显**：同上，避免用户把所有列关掉后只剩一张"只有操作列"的表。
3. **`config`「参数值」不可导出**：列表里敏感参数是打码展示（`displayValue` 返回 `••••`），若将来接列表导出会把打码值导出，口径不对。
4. **`session` 的派生列标为不可导出**：`userLabel` / `status` / `invalidReason` 是拼接或字典渲染，与后端 `ExcelField.key` 对不上。

## 6. 本次踩到的真坑（已修 + 已断言）

`SORTS` 用 `Map.of(...)`（不可变 Map）实现，**`get(null)` 会抛 NPE**。而"不传 `sort`"是最常见请求 → 文件列表与导出任务列表直接 500。两个仓储都已改为 `sort == null ? null : SORTS.get(sort)`，并写进断言 #103。
