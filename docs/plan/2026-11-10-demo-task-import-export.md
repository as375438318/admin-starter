## 3. 验收口径

| 编号 | 验收项 |
|---|---|
| `AC-IE-01` | 模板由后端生成：必填标记、格式说明、示例行、唯一性提示、填写须知页齐全 |
| `AC-IE-02` | 按模板填写 → 导入成功；`create_by`=导入人、`owner_id` 缺省=导入人、`status` 缺省=TODO |
| `AC-IE-03` | 含错误行 → 整批不落库，页面返回逐行错误（行号+字段+原因），并同时显示三个独立数字：总行数、出错行数、错误条数（`errors` 最多 200 条，另给未显示剩余条数） |
| `AC-IE-04` | 20000 行可导入；超过 20000 行或 50MB 直接拒绝并说明原因，不转异步 |
| `AC-IE-05` | 同一文件 5 分钟内重复提交被拒；失败后立即释放可重试 |
| `AC-IE-06` | 导入期间页面显示单一诚实提示（「正在校验并写入，请勿关闭页面」），按钮禁用，无百分比、无假阶段切换 |
| `AC-IE-07` | 2 万行导入不 OOM（SAX 解析） |
| `AC-IE-08` | 导出 ≤2000 行以 xlsx 响应直接下载；>2000 行以 JSON 返回 taskId；前端按 Content-Type 分支，不允许总是异步 |
| `AC-IE-09` | 导出异步用 SXSSF 流式写临时文件；文件在独立目录、按人隔离、24h 过期清理；文件管理列表与回收站无该文件 |
| `AC-IE-10` | 导出列随权限变化：`view` 明文、`mask` 打码、皆无整列缺失；行范围不越数据权限 |
| `AC-IE-11` | 导出任务非法流转被拒；启动补偿把超时 RUNNING 置 FAILED |
| `AC-IE-12` | 模板/导入/导出/任务完成均写 `sys_oper_log` |
| `AC-IE-13` | 无权限账号 403；页面不显示按钮 |
| `AC-IE-14` | 构建通过；`spec-lint` error 0 |
| `AC-IE-15` | `docs/design/import-export-onboarding.md` 可照着接入第二个模块；框架层为唯一实现 |

## 5. 风险与处置

| 风险 | 处置 |
|---|---|
| 解析 OOM | 解析强制 SAX；验收含 2 万行导入 |
| 同步导入占用连接 2–5 秒 | 写入设计 §4.2；接真实业务表前重新评估 |
| 重复提交 | 5 分钟文件指纹去重；成功保留、失败释放；按钮禁用 |
| 临时文件污染 | 独立目录常量单点定义；验收检查列表与回收站 |
| 进程崩溃任务悬挂 | 启动补偿：RUNNING 超 2 小时置 FAILED 并清理 |
